# ゲームルール

標準Sceneが参照する`StandardBoardGameConfig`とCoreの現行動作を説明します。実画面と操作手順は[画面・操作ガイド](SCREEN_GUIDE.md)、ゲーム内の説明文との食い違いは同ガイドの[注意点](SCREEN_GUIDE.md#5-現行画面の注意点)を参照してください。

## 1. ゲームの目的

プレイヤー1とプレイヤー2が交互に自分の駒を動かし、生存している自分の駒を1個でも相手の陣地へ到達させることが目的です。

相手駒をすべて消滅させても、その時点では勝利になりません。勝利条件は相手陣地への到達だけです。

## 2. 盤面と座標

- 標準盤面は横6列、縦10行、合計60マスです。
- 左下を`(0, 0)`、右上を`(5, 9)`とします。
- コードでは`GridPosition(Column, Row)`を使用します。
- Unityのローカル座標への変換はPresentationの`BoardGeometry`が担当します。

```text
y=9  プレイヤー2の陣地（プレイヤー1のゴール）
y=8  プレイヤー2の初期駒 ▼ × 6
 ...
y=1  プレイヤー1の初期駒 ▲ × 6
y=0  プレイヤー1の陣地（プレイヤー2のゴール）
     x=0 1 2 3 4 5
```

画面上では「▲ プレイヤー1の陣地」「▼ プレイヤー2の陣地」と表示します。「ゴール」という別ラベルは表示しません。

## 3. プレイヤーと初期配置

| 項目 | プレイヤー1 | プレイヤー2 |
|---|---|---|
| 駒の見た目 | 濃緑の上向き三角 ▲ | 濃緑の下向き三角 ▼ |
| 自分の陣地 | `y=0` | `y=9` |
| 相手の陣地 | `y=9` | `y=0` |
| 初期配置 | `y=1`の6マス | `y=8`の6マス |
| 初期戦闘力 | 各駒1 | 各駒1 |
| 手番 | 先手 | 後手 |

両プレイヤーの駒は同じ濃緑で、**三角の向きだけで所有者を区別します**。相手の陣地を向いている側が自分の駒です。

各駒は固有の`PieceId`、所有者、現在位置、戦闘力、`MovementProfileId`を持ちます。実際の`MoveDirections`は、移動プロファイルと現在の戦闘力から決まります。標準設定の初期駒は戦闘力1なので全8方向へ移動できます。

## 4. 手番と駒の選択

1. 手番中のプレイヤーは、自分の駒を1個選びます。
2. 選択した駒の合法な移動先が表示されます。
3. 移動先の選択、パワーランダム化、または合体のいずれかを1回実行します。リザーブがある場合は、自駒の選択の代わりにリザーブを選んで配置することもできます。
4. 正常な移動・戦闘・ランダム化・合体試行・リザーブ配置の後に手番が更新されます。合体は判定に失敗しても手番を消費します。

選択時の挙動は次のとおりです。

- 同じ駒を再度押すと選択を解除します。
- 別の自分の駒を押すと選択対象を変更します。
- 相手の駒だけを押しても選択されません。
- 合法手ではないマスを押してもコマンドは送信されません。
- 勝敗確定後は盤面入力を受け付けません。

## 5. 移動ルール

駒は、移動プロファイルが現在戦闘力に対して許可した`MoveDirections`へ1マスだけ移動できます。標準プロファイルは次のとおりです。

標準プロファイルの制限は戦闘力の帯域が上がるほど**累積**します。ただし駒が過去に失った方向を記録する方式ではありません。現在の実効戦闘力が下がれば、その値に対応する方向へ戻ります。

| 現在戦闘力 | 新たに失う方向 | 移動できる方向 |
|---:|---|---|
| 1 | — | 全8方向 |
| 2 | `NorthEast`（右上） | 7方向 |
| 3 | `SouthEast`（右下） | 6方向 |
| 4 | `NorthWest`（左上） | 5方向 |
| 5 | `SouthWest`（左下） | 4方向 |
| 6 | `West`（左） | 3方向（上・右・下） |
| 7 | `East`（右） | 2方向（上・下） |
| 8以上 | — | 2方向（上・下）のまま |

戦闘や特殊効果で戦闘力が変わると、次に合法手を計算した時点から移動方向も自動的に変わります。方向フラグは次の8種類です。

| フラグ | 相対座標 |
|---|---|
| `North` | `(0, +1)` |
| `NorthEast` | `(+1, +1)` |
| `East` | `(+1, 0)` |
| `SouthEast` | `(+1, -1)` |
| `South` | `(0, -1)` |
| `SouthWest` | `(-1, -1)` |
| `West` | `(-1, 0)` |
| `NorthWest` | `(-1, +1)` |

次の移動は不正です。

- 盤面外への移動
- 2マス以上離れたマスへの移動
- 現在戦闘力に対応する`MoveDirections`に含まれない方向への移動
- 自分の駒があるマスへの移動
- 自分の陣地への移動
- 自分の手番ではない駒の移動

相手の駒があるマスは合法な移動先になり、移動の代わりに戦闘を解決します。

## 6. 戦闘

敵駒のいるマスへ移動した場合、攻撃側と防御側は互いの`EffectiveCombatPower`を同時にダメージとして与えます。滞在中効果の一時戦闘力がある場合はそこから先に消費し、その後に通常の`CombatPower`を減らします。

```text
攻撃側の戦闘後戦闘力 = 攻撃側の戦闘力 - 防御側の戦闘力
防御側の戦闘後戦闘力 = 防御側の戦闘力 - 攻撃側の戦闘力
```

戦闘後の処理は次のとおりです。

- 攻撃側だけが生存: 防御側は消滅し、攻撃側は残り戦闘力で移動先へ入ります。
- 防御側だけが生存: 攻撃側は消滅し、防御側は残り戦闘力で元のマスに残ります。
- 両方が0以下: 両方とも消滅し、移動先は空きます。

### 数値例

| 攻撃側 | 防御側 | 結果 |
|---:|---:|---|
| 1 | 1 | 両方0になり、両方消滅 |
| 5 | 2 | 攻撃側が戦闘力3で移動先へ進む |
| 2 | 5 | 防御側が戦闘力3でその場に残る |

現在は「捕獲して自分の駒にする」という処理はありません。

## 7. 陣地、勝利、引き分け

- 自分の陣地には進入できません。
- 生存した自分の駒が相手の陣地へ入ると、そのプレイヤーの即時勝利です。
- 勝利後はリセットされるまでコマンドを拒否します。
- 相手駒を全滅させても勝利にはなりません。
- 次のプレイヤーに合法な操作がない場合、その手番を自動でパスします。
- 行動したプレイヤーにも相手にも合法な操作がなければ引き分けです。

戦闘で攻撃側が消滅した場合、相手陣地のマスを指定していても勝利にはなりません。

## 8. パワーランダム化、合体、特殊マス

### パワーランダム化

自分の手番に自駒を選び、「パワーランダム化」を押すと、その駒の通常戦闘力を1〜3のいずれかへ変更して手番を消費します。結果は現在値と同じになる場合もあります。変更後の実効戦闘力を使って、次に合法手を計算した時点から移動方向も更新されます。

`BlocksPowerRandomization`を持つ特殊効果が適用中または適用済みの駒は使用できません。標準の戦闘力増加効果はランダム化を禁止し、リザーブ駒獲得効果は禁止しません。

### 合体

合体は標準ゲームで有効です。自駒を選んで「合体」を押し、上下左右に1マス隣接する青表示の自駒を選ぶと合体を試行します。

どちらの駒も、まだ合体に成功したことがない必要があります。成功・大成功でできた駒は再び合体できません。確率判定で失敗した場合は、後の手番で再試行できます。

合体してできた駒も1駒として数えます。2駒が1駒になるため、所有数は1つ減ります。合体後の駒は、駒をひと回り大きくし、戦闘力の数字を白く縁取った黒字にして区別します。

- 25%で大成功し、両駒の通常戦闘力の合計に2を加えます。
- 50%で成功し、両駒の通常戦闘力の合計に1を加えます。
- 25%で失敗し、駒は変化しません。
- 成功・失敗のどちらでも手番を消費します。
- 成功時は最初に選んだ駒のID、位置、`MovementProfileId`、滞在中効果を維持します。永続効果の適用履歴は両駒から継承し、2個目の駒の滞在中効果は引き継ぎません。

### 特殊マス

標準盤面には2種類の特殊マスが配置されています。

**リザーブ駒獲得（紫）：** `(1,4)`と`(4,5)`に配置。どちらのプレイヤーも利用でき、停止した駒の所有者が戦闘力1・`standard`移動プロファイルの駒をリザーブへ獲得します。`EveryStop`なので、**駒が止まるたびに何度でも獲得できます**。同じ駒が同じマスへ戻ってきた場合も、2マスを行き来した場合も、回数の制限はありません。

獲得できるのは駒が新たにそのマスへ停止したときだけです。止まり続けても発動は1回で、いったん離れて再び止まる必要があります。すでに所有駒が6個ある場合はその回の獲得を見送りますが、適用履歴は残らないため、後で駒が減れば同じ駒で再び獲得できます。

**戦闘力アップ（シアン）：** `(2,2)`と`(3,7)`に配置。駒が滞在している間、戦闘力が+2されます。駒が移動して退出すると効果は解除され、再進入時に再び+2されます。

- `WhileOccupied`: マスにいる間だけ有効です。戦闘で消費された一時戦闘力は、退出して再進入するまで回復しません。
- `PermanentOncePerPiece`: 駒ごとに最初の停止時だけ発動し、適用履歴が残ります。
- `EveryStop`: 停止するたびに発動します。履歴も滞在中効果も残さないため、回数に上限がありません。
- 戦闘力増加と、盤上へ直接置かないリザーブ駒獲得の標準Handlerがあります。
- 移動元の滞在中効果を解除してから戦闘し、移動先の効果は攻撃側が生存した後に発動します。
- 同じセルの効果はIDの記載順に実行します。異なるLifetimeは同じセルに混在できません。
- 標準の戦闘力増加効果を保持している駒は「パワーランダム化」を使用できません。

### 駒の上限とリザーブ配置

- 各プレイヤーが所有できる駒は、盤上とリザーブを合わせて最大6個です。合体してできた駒も1駒として数えます。
- すでに6個所有している場合、新しいリザーブ駒は獲得できません。獲得を見送った理由は行動結果に表示されます。リザーブの配置は所有数を増やさず、盤上駒数と配置先で判定します。
- 画面右側の「駒 N / 6」表示は所有している駒の数です。
- 画面右側には、プレイヤー2を上、プレイヤー1を下にしたリザーブ一覧が常時表示されます。各カードには駒画像、戦闘力、移動プロファイルIDが表示されます。
- 手番中の自分のリザーブカードを押すと、その駒を配置するモードになります。黄色い枠が選択中のカードで、同じカードをもう一度押すと解除、別カードを押すと選択変更になります。相手のカードは確認できますが選択できません。
- 「リザーブ配置」を押した場合は、配置可能な先頭のリザーブ駒を選択します。配置モード中に押すと解除します。
- プレイヤー1（▲）は`y=1〜2`、プレイヤー2（▼）は`y=7〜8`の空きマスへ配置できます。自分・相手どちらの陣地にも配置できません。
- 配置は1回の行動として手番を消費します。配置先に特殊効果がある場合は、配置後にその効果が発動します。

## 9. 表示

| 表示 | 意味 |
|---|---|
| 濃緑の上向き三角 ▲ | プレイヤー1の駒 |
| 濃緑の下向き三角 ▼ | プレイヤー2の駒 |
| 駒上の白い数字 | 一時戦闘力を含む現在の実効戦闘力 |
| 琥珀色の枠 | 選択中の駒 |
| 白い点 | 移動可能、またはリザーブを配置可能な空きマス |
| 赤い枠 | 戦闘可能な敵駒のマス |
| 青い枠 | 合体候補の自駒 |
| シアン | 滞在中だけ有効な特殊マス |
| 紫 | 止まるたびリザーブ駒を獲得できる特殊マス |
| 太い外枠とラベル | 各プレイヤーの陣地 |
| 左上テキスト | 現在の手番、勝者、または引き分け |
| 手番下の結果欄 | 行動した▲ P1／▼ P2、戦闘・ランダム化・合体・特殊マスの結果。次の行動まで保持 |

陣地のマスは通常マスと違う無彩色で塗り、所有者の ▲▼ を敷きます。駒の色は両プレイヤーとも濃緑なので、陣地も駒も所有者は三角の向きで判別します。

盤面左側の凡例では、選択中・移動可能・戦闘可能・合体候補・合体した駒・リザーブ獲得・戦闘力+2の7種類を、盤面と同じ枠・点・塗りで示します。

特殊マスでは実際の増減と持続期間を表示します。上限による未獲得、適用済み効果の見送りも区別します。攻撃前に滞在中の強化が切れた場合は、強化解除と戦闘結果を順に表示します。これは行動後の説明であり、攻撃前の勝敗予告ではありません。

## 10. 入力とリセット

- マウス: 左クリック
- タッチ: プライマリタッチの押下
- UI: リセット、パワーランダム化、合体、リザーブ配置、リザーブカード、行動結果のスクロール欄、音量調節、リザルト上の入力は盤面クリックとして処理しません。

右下に単独配置した「リセット」を押すと、初期配置、戦闘力、効果状態、リザーブ、プレイヤー1の手番、選択、移動・合体候補、勝敗状態をすべて初期状態へ戻します。勝敗確定後はリザルトが背景操作を遮断し、「スタート画面に戻る」でタイトルへ移動します。
